# Storybook Friends — 3.9

Mark: slightly fuller head, teal jacket, modeled brass-rimmed goggles with inset glass and highlights, freckles, coral neckerchief with two moving tails, leather cross-body strap, rounded gusseted satchel, stitching, brass buckle and enamel pin.

Bark: broader and taller woody silhouette, eleven extra individually moving emerald/lime/copper crown leaves with raised veins, shoulder moss, spotted mushrooms, acorn pendant and five-petal blossom.

The existing articulated bodies, real directional lights, face animation, foot placement and collision dimensions are retained. Accessories attach to real 3D joints. Static pieces batch by material and nearest moving pivot; no particle emitters, per-frame node creation, extra lights or timers are added. Reduced motion settles the decorative joints; pause freezes them.

The complete existing automated suite and Android packed-resource checks cover both adventures, saves and 3D characters. Additional finishing checks cover batching, moving-joint availability, freeze and Reduced motion. The desktop studio preview is rendered from the actual models. Physical Android device testing remains outstanding.

Android uses package com.samkhaze.markandbark, version 3.9.0/code 390 and the original private release key so it can update 3.8 in place.
